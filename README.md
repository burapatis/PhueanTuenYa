# PhueanTuenYa iOS v0.6.8

TestFlight round with strengthened first-launch consent and usage guide.

## Status
- Based on the stable v0.6.x line through v0.6.7.
- First-launch consent: privacy/terms web links, uninstall notice, required acceptance checkbox.
- Simple usage guide: data-recording responsibility card and support web link.
- Xcode project build settings updated to Version 0.6.8 and Build 70.

## Main systems retained
- First launch consent and simple usage guide.
- SwiftData local persistence.
- Medication and health calendar local notifications.
- Blood pressure, feelings/symptoms, health calendar, SOS.
- CSV/PDF export through user-initiated Share Sheet.
- No login, no backend, no cloud sync.
