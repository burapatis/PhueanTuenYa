# SRS Traceability v0.3.1

## ปรับปรุงตามผลทดสอบ
- ความรู้สึก/อาการ: ปรับคำตัวเลือกให้ชัดขึ้น ลดความสับสนระหว่าง “สบายดี” กับ “ปกติ”
- SOS: รายการที่เป็นผู้ติดต่อหลักอยู่แล้วจะไม่แสดงปุ่มตั้งเป็นค่าหลักซ้ำ
- SOS: ปรับข้อความปุ่มตั้งค่าหลักให้สั้นลง เพื่อไม่ให้ตัดคำแนวตั้งและเหมาะกับผู้สูงอายุ
- ยังคงแนวทาง Local-first / SwiftData จาก v0.3.0

## สถานะ
- ไม่มี backend
- ไม่มี login
- ไม่มี cloud sync
- ข้อมูลอยู่ในเครื่อง
