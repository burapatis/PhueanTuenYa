# SRS Traceability — v0.3.0

## ทำแล้วในรุ่นนี้
- Offline-first local storage: ใช้ SwiftData ในเครื่อง
- Full user ownership: เพิ่ม ดู แก้ไข ลบ และล้างข้อมูลทั้งหมดได้
- No backend / no login: ไม่มีระบบสมัครสมาชิกหรือเซิร์ฟเวอร์
- Medical disclaimer: ยังแสดงข้อความว่าไม่ใช่เครื่องมือแพทย์
- Elderly-friendly UI: ยังใช้ card, ปุ่มใหญ่, สีแบ่งหมวด, dashboard กดได้

## ยังเป็นงานถัดไป
- Local notification scheduling จริงสำหรับรายการยาและนัดหมาย
- Export PDF/CSV จริง
- ปรับ migration schema เมื่อโครงสร้างข้อมูลนิ่งขึ้น
