# เพื่อนเตือนยา iOS v0.5.6 — Highlight Card Stripe Cleanup

## เป้าหมาย
ปรับการ์ดผลล่าสุด/วันนี้ให้มีพื้นสีชัดเจน แต่ลบแถบเส้นแนวตั้งด้านซ้ายออก เพื่อลดความรกและทำให้ UI ดูสะอาดขึ้นสำหรับผู้สูงอายุ

## สิ่งที่ปรับ
- การ์ดผลล่าสุด/วันนี้ยังคงใช้พื้นสีตามหมวดหมู่
- ลบแถบเส้นแนวตั้งด้านซ้ายออกจาก HighlightCard
- คงเส้นขอบสีอ่อนและเงาเพื่อให้แยกจากรายการทั่วไปได้
- ไม่เปลี่ยน logic ของ SwiftData, Notification, Export, Consent
