# เพื่อนเตือนยา iOS v0.1.9 — SRS Traceability Check

อ้างอิงไฟล์: CareSenior_App_Complete_Specification.docx

## เกณฑ์ที่นำมาใช้ตรวจใน v0.1.9

- ผู้สูงอายุเป็นกลุ่มเป้าหมายหลัก: ตัวอักษรใหญ่ ปุ่มใหญ่ ลดการพิมพ์
- แอปเป็นเครื่องมือช่วยจำ ไม่ใช่เครื่องมือแพทย์ ไม่วิเคราะห์/วินิจฉัยโรค
- Offline-first: ข้อมูลอยู่ในเครื่อง ไม่มี backend ไม่มี login
- ผู้ใช้ต้องควบคุมข้อมูลได้เอง: เพิ่ม ดู แก้ไข ลบ และล้างข้อมูลทั้งหมดในรุ่นถัดไป
- ส่งออกข้อมูลต้องเกิดจากการกดของผู้ใช้เองเท่านั้น
- หน้าหลักควรมี 6 เมนู และมีข้อความเตือนถาวร
- ปฏิทินสุขภาพใช้ Timeline/List View ไม่ใช้ปฏิทินแบบตารางเดือน
- SOS ต้องแจ้งก่อนเปิดแอปโทรศัพท์เพื่อป้องกันการกดพลาด

## สิ่งที่แก้ใน v0.1.9

- แก้ Health Calendar ไม่ให้ข้อความวันที่/เวลาตัดคำแนวตั้ง
- แยกตัวเลือกวันนัดและเวลานัดเป็น 2 แถว compact
- ปรับรายการนัดหมายเป็น Timeline/List View
- เพิ่ม PDF สรุปสุขภาพ 30 วันใน Settings แบบ mock
- เพิ่มคำเตือนก่อนส่งออกข้อมูลตาม SRS
- เพิ่มเอกสาร SRS traceability ไว้ในโปรเจกต์

## สิ่งที่ยังต้องทำในรุ่นถัดไป

- First-launch consent เต็มจอ
- Edit/Delete mock flow ทุกโมดูล
- Clear All Data
- Local persistence ด้วย SwiftData/Core Data
- PDF export จริง
- notification reminder จริง
