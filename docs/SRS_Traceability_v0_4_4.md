# SRS Traceability — v0.4.4

## Health Calendar Local Notification Foundation
- เพิ่มการแจ้งเตือนนัดหมายสุขภาพจากข้อมูลที่ผู้ใช้บันทึกไว้เอง
- ใช้ Local Notification ภายในเครื่องเท่านั้น
- ไม่มี backend / ไม่มี cloud sync
- ลบนัดหมายแล้วยกเลิก notification ที่เกี่ยวข้อง
- Settings มีปุ่มตรวจและตั้งเตือนนัดหมายใหม่และล้างแจ้งเตือนนัดหมาย

## Medical Safety
แอปยังเป็นเครื่องมือช่วยจำและบันทึก ไม่ใช่เครื่องมือแพทย์ ไม่วิเคราะห์โรค และไม่วินิจฉัยโรค
