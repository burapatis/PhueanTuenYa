# SRS Traceability — v0.2.6 Edit Awareness & Auto-scroll Polish

## เป้าหมายรุ่น
- ปรับ flow การแก้ไขให้ผู้ใช้รับรู้ทันทีว่าแอปตอบสนองแล้ว
- เมื่อกด “แก้ไข” ให้เลื่อนไปยังส่วนฟอร์มแก้ไขอัตโนมัติ
- เปลี่ยนหัวข้อฟอร์มให้ชัดว่าเป็นการ “แก้ไข” ไม่ใช่ “เพิ่ม”
- คงหลัก local-first, no backend, no diagnosis, no medical advice

## SRS alignment
- Full User Ownership: ผู้ใช้เพิ่ม ดู แก้ไข ลบข้อมูลได้เอง
- Elderly-friendly UX: ลดความสับสนด้วย feedback ทันทีหลังแตะปุ่ม
- One task per screen: แก้ไขรายการใดให้แสดงฟอร์มรายการนั้นอย่างชัดเจน
- Medical disclaimer: ยังคงข้อความไม่ใช่เครื่องมือแพทย์ในหน้าที่เกี่ยวข้อง

## Test checklist
- กดแก้ไขรายการยาแล้วเลื่อนไปฟอร์มแก้ไขยา
- กดแก้ไขความดันแล้วเลื่อนไปฟอร์มแก้ไขความดัน
- กดแก้ไขอาการแล้วเลื่อนไปฟอร์มแก้ไขอาการ
- กดแก้ไขนัดหมายแล้วเลื่อนไปฟอร์มแก้ไขนัดหมาย
- กดแก้ไข SOS แล้วเลื่อนไปฟอร์มแก้ไขผู้ติดต่อ
- หัวข้อฟอร์มเปลี่ยนเป็นคำว่า “แก้ไข...”
- ปุ่มบันทึกเป็น “บันทึกการแก้ไข”
- ไม่มี crash
