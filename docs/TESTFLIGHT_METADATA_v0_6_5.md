# TestFlight Metadata Draft — เพื่อนเตือนยา iOS v0.6.5

## App name
เพื่อนเตือนยา

## Short description
แอปช่วยเตือนยา บันทึกความดัน อาการ นัดหมายสุขภาพ และ SOS โดยข้อมูลอยู่ในเครื่อง

## Test notes
โปรดทดสอบการเพิ่มยา ตั้งเวลาเตือน บันทึกกินยา บันทึกความดัน บันทึกความรู้สึกและอาการ เพิ่มนัดหมายสุขภาพ ตั้งผู้ติดต่อ SOS ส่งออก PDF/CSV และตรวจว่าข้อมูลยังอยู่หลังปิด/เปิดแอป

## Safety note
แอปนี้ไม่ใช่เครื่องมือแพทย์ ไม่วิเคราะห์โรค ไม่วินิจฉัยโรค และไม่ใช้แทนคำแนะนำจากแพทย์

## Privacy note
ข้อมูลบันทึกอยู่ในเครื่องของผู้ใช้ ไม่มีระบบสมัครสมาชิก ไม่มี backend และผู้พัฒนาไม่สามารถเข้าถึงข้อมูลที่ผู้ใช้บันทึกได้
