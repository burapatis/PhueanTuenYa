# SRS Traceability v0.3.2

## Symptom Flow Clarity Polish

- ใช้หลัก Choice-first / ลดการพิมพ์
- ลำดับการบันทึกเริ่มจากภาพรวมที่ผู้สูงอายุเข้าใจง่าย: “วันนี้รู้สึกอย่างไร?”
- ต่อด้วยข้อมูลเชิงสังเกต: “มีอาการอะไรที่พบ?”
- เพิ่มตัวเลือก “ไม่มีอาการ” เพื่อลดความกำกวมระหว่างความรู้สึกปกติและอาการที่พบ
- หากเลือกอาการรุนแรงยังคงแสดง alert ให้ติดต่อแพทย์ โรงพยาบาล โทร 1669 หรือใช้ SOS/ผู้ติดต่อ
- ยังเป็น local persistence ด้วย SwiftData ไม่มี backend/login/cloud sync
