# SRS Traceability v0.3.6

## Medication Dosage Choice Wording Polish

- ปรับตัวเลือกหัวข้อ “ปริมาณ” ให้เป็นค่าที่สื่อความหมายจริงกับผู้ใช้
- นำ “ตามแพทย์สั่ง” ออกจากตัวเลือกปริมาณ เพราะไม่ระบุปริมาณยาอย่างชัดเจน
- เพิ่มตัวเลือกที่ใช้ได้จริง เช่น 1/4 เม็ด, 5 มล.
- คงแนวทาง Choice-first Input และมี “อื่น ๆ” สำหรับกรอกเองเมื่อไม่มีตัวเลือกที่ตรงกับฉลากยา
- ยังคงหลักการว่าแอปเป็นเครื่องมือช่วยจำ/บันทึก ไม่แนะนำยาและไม่ปรับขนาดยาแทนแพทย์
