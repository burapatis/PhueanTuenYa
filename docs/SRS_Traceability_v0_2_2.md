# SRS Traceability v0.2.2

## เป้าหมายรอบนี้
- ปรับ Home Dashboard ให้กระชับตามแนวคิดเมนู 6 หมวดแบบ Grid 2 คอลัมน์ x 3 แถว
- ลดข้อความซ้ำใน card เพราะมีสัญลักษณ์ chevron แสดงว่าแตะเข้าเมนูได้
- รวมไอคอนและชื่อ card ไว้บรรทัดเดียวเพื่อลดความสูง
- แก้การแสดงค่าความดันบนหน้าแรกไม่ให้เรียงแนวตั้ง
- เปลี่ยนคำใน SOS จาก “ตั้งหลัก” เป็น “ตั้งเป็นค่าหลัก”

## SRS Mapping
- Home Dashboard: วันที่/เวลา + progress ยา + เมนู 6 หมวดแบบ grid
- Elderly UI: ปุ่มใหญ่พอ, สี contrast สูง, ข้อความสั้นลง
- Blood Pressure: ค่าล่าสุดแสดงสั้น กระชับ อ่านในบรรทัดเดียวมากขึ้น
- SOS: คำสั่งเลือกผู้ติดต่อหลักชัดเจนขึ้น
