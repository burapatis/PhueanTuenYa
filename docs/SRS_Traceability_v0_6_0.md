# SRS Traceability v0.6.0

Real User Feedback Fixes after iPhone real-device test with 8 users.

- Home title adds house icon and layout is more compact.
- Blood pressure action text changed to “เพิ่มผลวัดความดัน”.
- Appointment date/time display uses Thai weekday/date format such as EEEE d MMM yyyy HH:mm.
- SOS action buttons use a two-column layout to avoid vertical text wrapping.
- User-selected/user-entered values are emphasized in blue.
- Save/edit result messages include the actual selected/edited values.
- Keeps local-only SwiftData, no backend, no login, consent, notifications, and export foundation.
