# SRS Traceability v0.5.2

- ปรับปุ่มเพิ่ม/บันทึกในโมดูลหลักให้เป็นปุ่มพื้นสีเด่นชัด
- ปรับการ์ดผลล่าสุด/รายการสำคัญให้มีสีพื้นชัดเจนขึ้น
- ปรับการเลื่อนหน้าจอเมื่อเปิดฟอร์มเพิ่ม/แก้ไขให้พยายามแสดงปุ่มบันทึกทันที
- รักษา SwiftData, Local Notifications, CSV/PDF Export และ First Launch Consent จากรุ่นก่อนหน้า
