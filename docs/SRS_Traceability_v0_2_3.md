# SRS Traceability v0.2.3

- เพิ่มขนาดชื่อการ์ดหน้าแรกให้สมดุลกับไอคอนและอ่านง่ายขึ้น
- ปรับตัวเลือกค่าความดัน SYS/DIA/ชีพจร เป็นแถวแนวนอน: ชื่อค่า, ปุ่มลบ, ตัวเลข, ปุ่มบวก
- ลดปัญหาตัวเลขในตัวเลือกความดันเรียงแนวตั้งหรือดูผิดรูป
- ยังคงพื้นที่กดขนาดใหญ่ เหมาะกับผู้สูงอายุ
- คงหลัก Dashboard แบบกดเข้าเมนูได้และข้อความไม่ใช่เครื่องมือแพทย์
