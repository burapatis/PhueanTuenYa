# SRS Traceability v0.2.10

- First Launch Consent: เปลี่ยน key เป็น v0.2.10 เพื่อให้ผู้ทดสอบเห็นหน้าข้อตกลงอีกครั้งหลังติดตั้ง/รันรุ่นใหม่
- Consent/Symptom Emergency Text: เพิ่มข้อความ SOS/ผู้ติดต่อในข้อความฉุกเฉิน
- Symptom Latest Card: แสดงทั้งความรู้สึกและ “อาการที่บันทึก” พร้อมเวลา
- Choice Feedback: ปุ่มเลือกความรู้สึกมีเครื่องหมาย checkmark เมื่อเลือกแล้ว
